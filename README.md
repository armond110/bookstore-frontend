# Marginalia — Frontend

React + Vite + Tailwind storefront for the Marginalia bookstore.

## Local setup

```bash
cd frontend
npm install
cp .env.example .env   # set VITE_API_URL to your backend URL
npm run dev              # starts on http://localhost:5173
```
